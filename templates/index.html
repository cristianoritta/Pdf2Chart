O que é o PDF2Chart?

O PDF2Chart extrai o texto de documentos PDF, utiliza inteligência artificial (Groq) para identificar entidades e vínculos entre elas, e gera um gráfico de análise compatível com o formato Alias ANX (IBM i2 Analyst's Notebook).

Como usar

  1. Configure sua API Key Groq no ícone de engrenagem.
  2. Arraste um PDF para a área central ou use + PDF.
  3. Aguarde a extração do texto e a análise pela IA.
  4. Explore o mapa interativo de vínculos no centro.
  5. Baixe o arquivo .ANX para importar no i2 Analyst's Notebook.

No canvas de vínculos

Shift+clique para seleção múltipla · Del para apagar · Pin para fixar cards · Salvar/Importar JSON · Copiar estrutura em Markdown.
