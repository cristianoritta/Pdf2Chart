O que é o PDF2Chart?

O PDF2Chart extrai o texto de documentos PDF, utiliza inteligência artificial (Groq) para identificar entidades e vínculos entre elas, e gera um gráfico de análise compatível com o formato Alias ANX (IBM i2 Analyst's Notebook).

Como usar

  1. Configure sua API Key Groq no ícone de engrenagem (canto inferior direito).
  2. Arraste um PDF para a tela ou clique para selecionar o arquivo.
  3. Aguarde a extração do texto e a análise pela IA.
  4. Revise entidades e vínculos na tela de resultados.
  5. Use Ver gráfico para explorar o mapa interativo de vínculos.
  6. Baixe o arquivo .ANX para importar no i2 Analyst's Notebook.
